# wf-radio

Radio button. It is exclusive with the other radios of its `wf-radio-group` or with the same `name`.

## Properties

| Property  | Attribute | Description                         | Type                | Default     |
| --------- | --------- | ----------------------------------- | ------------------- | ----------- |
| `name`    | `name`    | Radios sharing a name are exclusive | `string`            | `undefined` |
| `value`   | `value`   | Value of the radio                  | `string`            | `undefined` |
| `checked` | `checked` | Whether the radio is selected       | `boolean \| string` | `undefined` |

## Slots

| Slot | Description |
| ---- | ----------- |
|      | Label text  |
