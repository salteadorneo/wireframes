# wf-link

Link.

## Properties

| Property | Attribute | Description                           | Type     | Default     |
| -------- | --------- | ------------------------------------- | -------- | ----------- |
| `href`   | `href`    | URL the link points to                | `string` | `undefined` |
| `target` | `target`  | Where to open the link, e.g. `_blank` | `string` | `undefined` |

## Slots

| Slot | Description |
| ---- | ----------- |
|      | Link text   |
