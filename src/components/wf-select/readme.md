# wf-select

Dropdown select.

## Properties

| Property      | Attribute     | Description                          | Type                           | Default                        |
| ------------- | ------------- | ------------------------------------ | ------------------------------ | ------------------------------ |
| `width`       | `width`       | Width                                | `string`                       | `undefined`                    |
| `maxWidth`    | `max-width`   | Maximum width                        | `string`                       | `undefined`                    |
| `options`     | `options`     | Comma separated options              | `string`                       | `'Option 1,Option 2,Option 3'` |
| `placeholder` | `placeholder` | Text shown while nothing is selected | `string`                       | `undefined`                    |
| `value`       | `value`       | Selected option                      | `string`                       | `undefined`                    |
| `variant`     | `variant`     | Size                                 | `"sm" \| "md" \| "lg" \| "xl"` | `undefined`                    |
