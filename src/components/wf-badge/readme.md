# wf-badge

Small label for statuses, tags and counters.

## Properties

| Property          | Attribute          | Description      | Type                           | Default     |
| ----------------- | ------------------ | ---------------- | ------------------------------ | ----------- |
| `backgroundColor` | `background-color` | Background color | `string`                       | `undefined` |
| `color`           | `color`            | Text color       | `string`                       | `undefined` |
| `borderColor`     | `border-color`     | Border color     | `string`                       | `undefined` |
| `variant`         | `variant`          | Size             | `"sm" \| "md" \| "lg" \| "xl"` | `undefined` |

## Slots

| Slot | Description |
| ---- | ----------- |
|      | Badge text  |
