# wf-radio-group

Groups radios and lays them out.

## Properties

| Property    | Attribute   | Description          | Type                | Default    |
| ----------- | ----------- | -------------------- | ------------------- | ---------- |
| `direction` | `direction` | Layout direction     | `"row" \| "column"` | `'column'` |
| `gap`       | `gap`       | Space between radios | `string`            | `'.5rem'`  |

## Slots

| Slot | Description         |
| ---- | ------------------- |
|      | `wf-radio` elements |
