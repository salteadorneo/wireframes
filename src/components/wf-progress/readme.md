# wf-progress

Progress bar. Without `value` it shows an indeterminate animation.

## Properties

| Property   | Attribute   | Description   | Type                           | Default     |
| ---------- | ----------- | ------------- | ------------------------------ | ----------- |
| `value`    | `value`     | Current value | `number \| string`             | `undefined` |
| `max`      | `max`       | Maximum value | `number \| string`             | `100`       |
| `width`    | `width`     | Width         | `string`                       | `undefined` |
| `maxWidth` | `max-width` | Maximum width | `string`                       | `undefined` |
| `variant`  | `variant`   | Size          | `"sm" \| "md" \| "lg" \| "xl"` | `undefined` |
