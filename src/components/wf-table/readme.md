# wf-table

Table with empty cells.

## Properties

| Property     | Attribute     | Description                             | Type                | Default     |
| ------------ | ------------- | --------------------------------------- | ------------------- | ----------- |
| `rows`       | `rows`        | Number of rows, header included (1-100) | `number \| string`  | `3`         |
| `cols`       | `cols`        | Number of columns (1-100)               | `number \| string`  | `3`         |
| `header`     | `header`      | Render the first row as a header        | `boolean \| string` | `undefined` |
| `width`      | `width`       | Width                                   | `string`            | `undefined` |
| `maxWidth`   | `max-width`   | Maximum width                           | `string`            | `undefined` |
| `cellHeight` | `cell-height` | Height of the cells                     | `string`            | `'2.5rem'`  |
