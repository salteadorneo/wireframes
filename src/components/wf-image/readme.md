# wf-image

Image placeholder.

## Properties

| Property       | Attribute       | Description                            | Type     | Default     |
| -------------- | --------------- | -------------------------------------- | -------- | ----------- |
| `width`        | `width`         | Width                                  | `string` | `undefined` |
| `height`       | `height`        | Height                                 | `string` | `undefined` |
| `aspectRatio`  | `aspect-ratio`  | Aspect ratio, e.g. `16/9`              | `string` | `undefined` |
| `text`         | `text`          | Text shown inside the placeholder      | `string` | `undefined` |
| `borderRadius` | `border-radius` | Border radius, e.g. `50%` for a circle | `string` | `undefined` |
